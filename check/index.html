Если анимаций нет

Значит в системе включён режим «уменьшить движение». Сайт его намеренно уважает — так делают ради людей, которым движение на экране вызывает недомогание.

  1. Windows 11: Параметры → Специальные возможности → Визуальные эффекты → включить «Эффекты анимации»
  2. Windows 10: Параметры → Специальные возможности → Дисплей → «Показывать анимацию в Windows»
  3. macOS: Системные настройки → Универсальный доступ → Дисплей → снять «Уменьшение движения»
  4. iPhone: Настройки → Универсальный доступ → Движение → выключить «Уменьшение движения»
  5. Android: Настройки → Спец. возможности → «Удалить анимации» выключить

После изменения обновите страницу — перезапускать браузер не нужно.
